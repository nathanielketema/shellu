# Shellu

Shell in zig.

## Start

```console
zig build run
```

Test could be run as:

```console
cd src
zig build test
```

## System dependencies

- [zig](https://ziglang.org/)
- [readline](https://tiswww.case.edu/php/chet/readline/rltop.html)
