# Shellu

A POSIX compatible shell implemented in [zig](https://ziglang.org/).

## Start

```console
zig build run
```

You only need `zig 0.16.0` in order to run it.

## Implemented features

- [x] Background jobs
- [x] Command completion
- [x] Command History
- [x] Redirection
- [x] Pipes
- [x] Variables
- [x] Builtins
  - [x] cd
  - [x] pwd
  - [x] echo
  - [x] jobs
  - [x] type
  - [x] declare
  - [x] history
  - [x] exit
- [x] Helpful errors
